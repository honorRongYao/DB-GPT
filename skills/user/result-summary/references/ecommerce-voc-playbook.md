# 电商 + VOC 场景口径

面向电商运营与评论（VOC）分析场景，给出维度定义、组合分析套路与常见误读。

## 一、商品维度

- **ASIN / 子体**：最小销售单元
- **parent_asin / 父体**：变体聚合单元。看单品看 ASIN，看系列看父体
- **品类层级**：category_1 ~ category_4，逐级收窄。跨层级对比要先对齐层级
- **配件识别**：`is_parts` 标记。分析成品大盘时必须排除配件
- **去重口径**：同一天同一 parent_asin 可能有多条记录，口径要先定死并在结论里写明

## 二、销量与销售额

- **月销量 / 月销售额**：`units_month` / `revenue_month`
- **隐含均价** = 销售额 ÷ 销量，反映价格带位置，是推算值
- **份额** = 单品销量 ÷ 品类总销量。先明确分母是哪个品类层级
- **动销**：有销量记录的商品数 ÷ 在架商品数
- **趋势判定**：至少两个时点才能说趋势；只有首尾两点时，说"两端对比"而非"持续上升 / 下降"

## 三、评论 / VOC 维度

- **评论量**：反映声量，不等于满意度
- **星级分布**：1-5 星结构。看差评率（1-2 星占比）通常比看均值更有信息量
- **情感倾向**：正面 / 中性 / 负面占比
- **主题分布**：按评论内容聚类出的话题（质量、物流、性价比、外观、耐用性……）
- **差评归因**：负面评论集中的主题，即改进优先级
- **时序关系**：差评率上升通常滞后于销量下滑，可作先行指标观察

## 四、组合分析套路

1. **销量 × 评论**：销量涨但差评率也涨 → 放量伴随体验下降，有隐患
2. **销量 × 星级**：销量涨且星级稳 → 健康增长；销量涨星级跌 → 增长质量差
3. **价格带 × 销量**：判断品类是高价拉动还是低价放量
4. **主题 × 差评**：定位最该修的产品问题
5. **自身 × 竞品**：份额变化比绝对销量更能说明竞争态势

## 五、常见误读

- 只看总量不看结构：总量涨可能由少数单品拉动，其余在萎缩
- 把声量当口碑：评论多只说明卖得多或争议大
- 用首尾两点推断趋势：中间月份可能反转
- 忽略去重口径：按 dt + parent_asin 去重后总量偏低，结论必须标注
- 把配件销量算进成品大盘
- 用绝对销量横向比较不同生命周期的商品：新品高增速多半是基数效应

## 六、结论语气

- 数据支持到什么程度就说到什么程度，不外推
- 归因说"最可能"，并说明缺哪些字段所以无法确认
- 涉及投放 / 库存建议时，说明依据的只是销量数据，不含成本与利润维度
