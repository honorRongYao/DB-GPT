# 通用指标口径

生成结论时按此解释指标，避免口径混用。

## 一、时间口径

- **同比**：与去年同期比，消除季节性。例：202607 vs 202507
- **环比**：与上一周期比，看短期动能。例：202607 vs 202606
- **累计**：区间求和。注意区间是否含首尾
- **粒度**：日 / 周 / 月 / 季 / 年，不同粒度不可直接比较

计算注意：

- 同比、环比必须两个周期口径一致（同样去重、同样过滤条件）
- 基数为 0 或极小时，百分比会失真，应改用绝对量描述
- 有缺失周期要先说明，不能默认连续

## 二、规模类

- **总量**：区间内求和
- **均值**：总量 ÷ 数量。要区分算术均值与加权均值
- **隐含均价**：销售额 ÷ 销量。这是推算值，不是结果中的原生字段，必须标注"约"
- **中位数**：对异常值不敏感，分布偏斜时比均值更能代表"典型值"

## 三、结构类

- **占比**：部分 ÷ 整体。写之前先明确分母是谁
- **Top-N 集中度**：前 N 名合计占比，衡量头部集中程度
- **价格带分布**：按价格区间分桶后的销量 / 销售额结构
- **覆盖 / 渗透**：出现的商品数 ÷ 全量商品数

## 四、变化类

- **绝对增量**：本期 − 上期（件、元）
- **增长率**：(本期 − 上期) ÷ 上期
- **贡献度**：某部分的增量 ÷ 整体增量，衡量谁在拉动增长
- **复合增速**：跨多期时的平均增速

## 五、口径陷阱（每次都要检查）

1. **去重规则**：同一商品在同一天是否只有一条记录？去重会让总量偏低
2. **过滤条件**：是否排除了非目标品类、配件、已下架商品
3. **预览 vs 全量**：结果预览行数可能小于总行数，不能把预览当全量
4. **先筛后聚合 / 先聚合后筛**：顺序不同，结果不同
5. **单位**：件 / 元 / 人，跨单位不能相加

## 六、表达规范

- 精度合理：金额到分或万元，百分比到一位小数
- 大数用万 / 亿，避免一长串数字
- 推算值写"约""推算"，与原生字段区分开
- 只用两个时点时，说"两端对比"，不说"持续上升 / 下降"
