# 输出模板：业务向（默认）

**适用**：业务、运营、管理层阅读。前端按纯文本渲染（`whitespace-pre-wrap`）。

## 结构

```
📌 结论
一句话直接回答用户问题，必须带最关键的数字，不超过 60 字。

🔍 关键发现
用 1. 2. 3. 编号，按重要性排序，2-4 条。每条一行，写成：现象 + 数字 + 对比 + 业务含义。
涨跌用 ↑ ↓ 标注。

💡 建议行动
用 1. 2. 编号，2-3 条可直接执行的动作，不写空泛表述。

⚠️ 数据说明
一到两句，只写口径、局限或置信度。数据充分且无歧义时可省略本段。
```

## 排版规则

- 段与段之间空一行
- **不使用 Markdown 语法**：`**`、`##`、`-`、表格、代码块都不行——前端不渲染 Markdown，符号会原样显示出来
- 可用的视觉手段：emoji 段标、`↑ ↓` 涨跌、编号、数字本身
- 全角标点，中文与阿拉伯数字统一

## 示例

```
📌 结论
电动牙刷 2026H1 销量 4781 万件、销售额 36.94 亿元，隐含均价约 77.3 元/件。

🔍 关键发现
1. 半年销量 4781 万件、销售额 36.94 亿元，是本结果唯一可确认的量化结论。
2. 隐含均价约 77.3 元/件（推算值，销售额÷销量），暗示品类重心偏中低价位，需价格带数据验证。
3. 结果仅 1 行汇总，无月度拆分与同比对照，无法判断增长是快是慢。

💡 建议行动
1. 按月（202601-202606）拆分看趋势与波动，定位增长来源。
2. 按价格带或品牌拆分，确认是高价拉动还是低价放量。

⚠️ 数据说明
按 dt + parent_asin 去重后统计，总量可能低于实际全量；隐含均价为推算值，置信度较低。
```
