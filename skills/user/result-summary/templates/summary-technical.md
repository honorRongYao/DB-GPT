# 输出模板：技术向

**适用**：分析师、数据同学，需要口径可追溯。同为纯文本渲染。

## 结构

```
📌 结论
一句话核心结论 + 关键数字。

🔍 关键发现
1. 2. 3. 编号，每条：现象 + 精确数字 + 对比基准 + 判断依据。

🧮 口径与算法
逐条写明：表与去重规则、过滤条件、时间口径、派生指标的计算方式。
涉及推算值的，写明公式。

💡 建议行动
可执行动作，并注明验证方式（如"补做 XX 拆分以验证"）。

⚠️ 局限与置信度
- 字段缺失：结果中不包含哪些维度，因此哪些结论无法得出
- 口径影响：去重 / 过滤可能造成的偏差方向与量级
- 置信度分级：高（原生字段直接支持）/ 中（派生指标）/ 低（推断）
```

## 与业务向模板的差别

| | 业务向 | 技术向 |
|---|---|---|
| 口径说明 | 一两句 | 独立成段，写全公式与过滤条件 |
| 数值精度 | 可简化为万 / 亿 | 保留精确值 |
| 字段名 | 禁止出现 | 允许出现表名、字段名 |
| 置信度 | 可选 | 必写，并分级 |
| 篇幅 | 控制在 400 字内 | 可到 800 字 |
